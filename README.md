# Player Menu — your gym app

A React + Vite site with 5 pages: Character (about you), Fuel Log (calorie
tracker), Training (gym routine), Loadout (gymwear), Support Quest (donate).
Styled like a retro game menu. Hopefully it can help people get to know me more and live healthier through tracking calories and an AI coach.
Keep in mind that the coach might just roast you lol.
